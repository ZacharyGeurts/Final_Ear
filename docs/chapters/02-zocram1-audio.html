GAC1 frame kinds

GAC1 is not MPEG. Three frame types cover most field audio:

  • KEY — zlib-compressed PCM keyframe (lossless round-trip in lossless profile).
  • PRED — int16 delta from previous frame — where patrol and dish audio shrinks versus naked PCM.
  • SILENCE — explicit zero runs — machine hears perimeter quiet without burning your cochlea on noise-shaped zeros.

Profiles in data/gac1-v1.json: lossless, fast, binaural_safe, cochlear_safe, patrol. Die telemetry mirrors rack state on data_bus[57–59]; ZOCRAM1 is transport and witness, not a replacement for ThermoAccountant.

ZOCRAM1 container

Files use extension .zocr. Header + segment index + sealed payloads — same discipline as GRKMF video envelopes, tuned for the ear:

ZOCR header → segment index → [meta segment | frame segments…]
Each segment: ZOCR magic + SHA256 + GAC1 payload

Meta JSON carries profile, sample rate, channels, entropy mean, sovereign time, and provenance weave hash. Verify before vault. Stoard quarantines failed seals; Veritas rejects playback when provenance mismatches pattern weave.
